# 上手：从零接上企业微信

按顺序做完下面 7 步，就能在手机上的企业微信里和电脑上的 Claude Code 会话互发消息。整个过程约 15 分钟。

下文 `<仓库目录>` 指你克隆本仓库的位置（例如 `~/code/cc-im-bridge`），替换成你自己的。

## 0. 准备

| 需要 | 说明 |
|---|---|
| macOS | 中转靠 launchd 常驻；其他系统暂不支持 |
| Node 22 或更新 | 在终端执行 `node -v` 确认。用 nvm 且默认版本较低时，先 `nvm use 22`（或更新），后面所有命令都在这个终端里执行 |
| Claude Code 2.1.3xx 或更新 | 终端里要能执行 `claude`（Desktop 用户也要装命令行版，用来安装插件） |
| 企业微信 | 能在客户端「工作台」里创建智能机器人。找不到入口时先把客户端升到最新版；企业不允许成员自建时，请管理员建好后把 Bot ID 和 Secret 给你 |

克隆仓库：

```bash
git clone https://github.com/jianxinliu/cc-im-bridge.git <仓库目录>
```

不需要 `npm install`：中转没有第三方依赖。

## 1. 在企业微信里建机器人

依据企业微信帮助中心[《如何获取 Bot ID 和 Secret》](https://open.work.weixin.qq.com/help2/pc/21677)：

1. 打开企业微信客户端，进入「工作台」→「智能机器人」→「创建机器人」→「手动创建」。
2. 填名称、头像、简介，在页面下方选「API 模式创建」。
3. 在「API 配置」里，连接方式选**「使用长连接」**（不要选 URL 回调：长连接由本机主动连出去，不需要公网地址）。
4. 页面上会出现 **Bot ID** 和 **Secret**。Secret 只显示一次，先记在安全的地方（腾讯云文档：[丢失后可在机器人详情页重新生成](https://intl.cloud.tencent.com/zh/document/product/1316/84454)）。
5. 「可见范围」设成只有你自己，其他保持默认，保存。

不要把 Bot ID 和 Secret 贴进 Claude Code 对话或任何聊天里。

## 2. 写入机器人配置

```bash
<仓库目录>/scripts/setup-wecom.sh
```

依次输入 Bot ID、Secret（输入时不显示）、你的企微 userid。不知道 userid 就直接回车，第 6 步会拿到。

配置写在 `~/.cc-im-bridge/wecom.json`，权限 600。

## 3. 启动中转

```bash
CC_IM_NODE=$(command -v node) <仓库目录>/scripts/launchd.sh install
```

中转会开机自启、退出后自动拉起。确认连上了：

```bash
tail -5 ~/.cc-im-bridge/relay.log
```

看到「企微：已连接」即可。看到「认证失败」就是 Bot ID 或 Secret 填错了，重做第 2 步，再执行一次上面的 install。

## 4. 安装会话插件

```bash
claude plugin marketplace add <仓库目录>
```

```bash
claude plugin install cc-im-bridge@cc-im-bridge-local --scope user
```

装好后**重启 Claude Desktop**（⌘Q 再打开），终端里的 `claude` 会话也要重开。已经开着的会话不会自动加载新插件。

## 5. 登记审批钩子

这一步让「Claude 要你批准某个操作」时也能在企微里点批准。不做也能收发消息，只是审批只能在电脑上点。

编辑 `~/.claude/settings.json`，在 `hooks` 里加一项（没有 `hooks` 就新建）。两个路径都写绝对路径：node 用第 3 步 `command -v node` 打出的那个，脚本用仓库里的 `hooks/permission-request.mjs`。

```json
"hooks": {
  "PermissionRequest": [
    { "matcher": "*", "hooks": [{ "type": "command", "timeout": 660,
      "command": "/绝对路径/node /绝对路径/cc-im-bridge/hooks/permission-request.mjs" }] }
  ]
}
```

改前先备份这个文件。中转没在跑时钩子什么都不做，照常本地弹框，不会卡住。

## 6. 把自己加进白名单

在企微里找到刚建的机器人，给它发一句「你好」。

- 如果第 2 步填了 userid，跳到第 7 步。
- 没填的话，机器人会回「你的 userid 是 xxx，不在白名单里」。把 xxx 填进 `~/.cc-im-bridge/wecom.json` 的 `allowUsers`（如 `"allowUsers": ["xxx"]`），再执行一次第 3 步的 install 重启中转。

只有白名单里的人能用：能发消息进会话，就能让 Claude 在你电脑上执行命令。

## 7. 试一下

1. 在电脑上开一个 Claude Code 会话（Desktop 或终端都行），输入 `/im-status`，应显示「状态：已连接」。
2. 在企微里发「会话」，回一张会话列表卡片，点它的编号。
3. 发一句「列一下当前目录有哪些文件」，企微里先出现「思考中」，再变成回复。

能走通就装好了。日常用法见 [README](../README.md) 的「在企微里怎么用」。

## 出了问题

| 现象 | 原因与处理 |
|---|---|
| 机器人回「你的 userid 是 …，不在白名单里」，日志里有「拒绝白名单外用户」 | 做第 6 步 |
| 日志里反复「getaddrinfo ENOTFOUND」 | 本机断网或 DNS 不通，网络恢复后会自动重连 |
| 日志里「同一机器人在别处建立了新连接」，之后不再重连 | 同一个机器人在别处（另一台电脑、另一个程序）也建了长连接，服务端把这边踢下线了。只保留一处，然后执行第 3 步的 install |
| 会话卡片里没有某个会话 | 该会话是装插件前打开的，重开它；或在会话里 `/im-status` 看状态 |
| `/im-status` 显示「中转未连接」 | 中转没在跑：`<仓库目录>/scripts/launchd.sh status` 查看，`tail ~/.cc-im-bridge/relay.log` 看原因 |
| 企微里突然收不到回复和审批了 | 你在电脑上给某个会话发过消息，中转认为你回到了电脑前（企微会收到一条「你在电脑上给 X 发了消息…」）。在企微里直接发一条消息或说「离开」就恢复 |
| 点卡片提示「已过期」 | 中转重启过，之前的卡片作废。会话卡片重新发「会话」；审批等会话重新发起 |
| 会话说「企微只能发文字，发不了图」 | 该会话是在插件加上发文件功能之前开的，模型看到的还是旧的工具定义。在会话里执行一次 `/compact` 或新开会话 |
| `npm test` 报 `bad option: --test-timeout` | Node 版本太低，见第 0 步 |

## 卸载

```bash
<仓库目录>/scripts/launchd.sh uninstall
```

```bash
claude plugin uninstall cc-im-bridge@cc-im-bridge-local
```

再从 `~/.claude/settings.json` 删掉 `hooks.PermissionRequest`。数据目录 `~/.cc-im-bridge/`（配置、日志、企微发来的文件）要不要留，自己决定。
